# Contact Database & Website Launch Support

Workspace for tracking the contact database cleanup and
the website launch handoff. I kept in GitHub so progress, decisions, and file
versions are never lost in email threads.

## What lives here

| File | Purpose |
|---|---|
| `index.html` | Placeholder homepage, ready to publish via GitHub Pages while the full site is finished |
| `CONTACT_LIST_LOG.md` | Dated log of every contact-list import batch (source, count, status) |
| `.github/ISSUE_TEMPLATE.md` | Standard template for logging outreach/data tasks as trackable issues |
